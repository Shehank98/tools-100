💡 How It Works

  • Paste any JSON text and click Format to pretty-print it with indentation.
  • Use Minify to strip all whitespace for compact JSON ready for APIs.
  • The validator detects syntax errors and shows the exact position in the JSON.
  • Choose between 2 spaces, 4 spaces, or tab indentation for formatted output.
  • All processing happens entirely in your browser — no data is ever sent to a server.

🐛 Common JSON Errors

  • Trailing commas — JSON does not allow a comma after the last item in an array or object.
  • Single quotes — Keys and string values must use double quotes ("), not single quotes.
  • Unquoted keys — All object keys must be quoted strings: {"key": "value"}.
  • Comments — Standard JSON does not support comments (// ... or /* ... */).
  • Undefined / NaN / Infinity — These JavaScript values are not valid in JSON.
