What is Base64?

        

          Base64 is an encoding scheme that converts binary data into an ASCII text string using 64 printable characters (A–Z, a–z, 0–9, +, /). It is widely used to embed binary data—images, fonts, files—inside JSON, HTML, CSS, XML, and email payloads.
        

        
    
          
  • Encoding makes binary data safe to transmit over text-only channels.
    • 
          
  • URL-safe Base64 replaces + with - and / with _ so the string is safe in URLs without percent-encoding.
    • 
          
  • Base64 output is approximately 33% larger than the original input.
    • 
          
  • Base64 is not encryption — it is easily reversible by anyone.

  • base64 file — encode on Linux
