💡 PDF Merge Tips

  • Add as many PDFs as you need - there is no file count limit.
  • Drag and drop the file cards to change the order before merging.
  • All page sizes and orientations are preserved in the merged output.
  • All processing happens entirely in your browser - nothing is uploaded.
  • Use the PDF Compressor after merging if the combined file is too large.

Frequently Asked Questions

Is there a file size limit?

No. OneKit's Merge PDF supports files of any size. The only constraint is your device's available memory.

Are my PDFs uploaded anywhere?

Never. All merging happens locally in your browser using JavaScript. Your files are completely private.

How many PDFs can I merge?

As many as you need. Add files one batch at a time using the "Add more PDFs" button.
